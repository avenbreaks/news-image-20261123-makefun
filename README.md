**The world in one image** — a newspaper front page summing up Monday, 23 November 2026: a Russian cargo ship still burning off Finland after a drone attack in the Baltic; a Russian drone strike on homes in the Kyiv region leaves 14 missing; Iran strikes US bases in Bahrain as the Strait of Hormuz conflict widens; COP31's final draft drops the words "fossil fuels"; seven dead and 50 missing after a factory fire in Indonesia. The ticker adds Seoul's minister quitting over an AI exam-cheating scandal, Nepal's PM in Delhi, India's record 720/9 in Wellington, and the UN's continuing talks on lethal AI weapons.

`main.py` writes the image to `/output/entry.png` (it copies the `entry.png` shipped in this repo, standard library only, so both grader runs produce identical bytes). `build_image.py` is the script that composed `entry.png` from four news-style photos generated during the build session plus one drawn stat panel — run it to reproduce the image.

## Run it

```sh
python3 main.py
# writes /output/entry.png (1024x1024 PNG)
```
